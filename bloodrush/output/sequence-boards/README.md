# Blood Rush — 3x3 Sequence Boards

These boards are low-cost visual story tests before video generation. Each prompt keeps character identity, environment continuity, and shot direction in separate reference roles.

## Cold-open exploration order

1. `01-rooftop-pursuit` — visceral supernatural promise
2. `02-video-haven-handoff` — Kai's ordinary job collides with vampire logistics
3. `03-bathroom-transformation` — Mara-centered audience-entry alternative
4. `04-wet-campus-encounter` — restrained character mystery after the first symptom

An approved board may be used as a composition and shot-progression reference for video. The original character sheets remain the definitive identity references, and the clean environment seed remains the definitive geography reference.
