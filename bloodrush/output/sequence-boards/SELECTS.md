# Blood Rush — Sequence Board Selects

## Use rule

The four grids below are composition and shot-progression references only. They are not identity masters. Nano Banana created useful staging and lighting but drifted faces, age, accessories, and some wardrobe details. For video generation, the original character sheets remain the definitive identity assets, the clean environment images remain the definitive location assets, and the grid controls only composition, action order, screen direction, pacing, and camera language.
