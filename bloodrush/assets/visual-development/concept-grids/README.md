# Exploratory Concept Grids

These images established early palette, locations, and montage ideas. They are not canonical identity references because several predate the current character sheets.

Use them for:

- Neon Gothic palette and lighting
- Video Haven, campus, rooftop, gym, party, and bathroom concepts
- shot rhythm and composition exploration

Do not use them to lock:

- character faces
- exact group membership
- costume continuity
- final signage or architecture

New character-containing generations must use the canonical sheets under `../../characters/`.
