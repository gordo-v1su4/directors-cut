# TIKTOK DRUG DYNASTY

Netflix series — **Stage 3 Concept Package** (example).

**Tagline:** Fame is the new cartel.

## The edit

Not: drug dealers invent meth / guns-first cartel origin.

**Is:** two girls accidentally manufacture the first viral narcotic designed for the attention economy.

## Pilot engine

They are **not criminals yet**. They think it’s beauty / sleep / focus / mood / livestream wellness. Obsession scales. Unregulated analog = legally sellable at first.

## Tone

euphoric → dangerous → seductive → accidental → entrepreneurial → then horrifying.
